# ЛР-3. MILP-модель дискретного выбора - вариант 9

**Задача:** маршрутизация (TSP) с потоковой формулировкой устранения подциклов, 12 вершин.

**Индивидуальные параметры:** N=4, Q=2, Y=26, отсюда $V = 1 + ((17 \cdot 4 + 7 \cdot 2 + 26) \bmod 20) = 9$; seed = 10204.

## Установка и запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python main.py            # полный цикл, ~30 с (ветвление на n=40)
```

Одна команда прогоняет всё: генерация данных, MILP и LP-релаксации в двух
формулировках (MTZ и Gavish-Graves), независимая проверка, жадная эвристика,
сценарии, анализ big-M, кривая масштаба, логи, CSV и графики.

## Структура

```
main.py                 # оркестратор полного цикла
src/generate_data.py    # генерация данных (seed 10204)
src/model.py            # MILP/LP: MTZ + однотоварный поток (scipy.optimize.milp, HiGHS)
src/verify.py           # независимая проверка допустимости (NumPy, без объекта солвера)
src/heuristic.py        # жадная эвристика: ближайший сосед + 2-opt
src/scenarios.py        # базовый / дефицитный / стрессовый сценарии
src/scaling.py          # кривая "время / зазор" для n = 10, 12, 20, 40
data/tsp_12.json        # данные варианта (координаты + матрица расстояний)
outputs/logs/           # логи HiGHS и полный вывод прогона
outputs/results/        # CSV с решениями, сценариями, зазорами; verification.txt
outputs/figures/        # туры по сценариям, кривая масштаба, сравнение LP-релаксаций
report/report.md        # отчёт
```

## Стек

Python 3.11; решатель HiGHS через `scipy.optimize.milp` (SciPy 1.17.1,
встроенный HiGHS 1.12.0). Модель задаётся прямо матрицами (A, lb, ub), отдельный
слой Pyomo или PuLP не нужен. Независимая проверка - NumPy; данные и результаты
- JSON/CSV; графики - matplotlib.
